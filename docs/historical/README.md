# Σεισμική Χαρτομαντεία · Δεύτερη ερευνητική φάση

Ερευνητικό πακέτο EL/EN με 1.326 ιστορικές καταχωρίσεις. Ο κυρίως κατάλογος έχει 1.182 και το παράρτημα του συστήματος 36 φύλλων έχει 144. Ο αρχικός κατάλογος των 312 διατηρείται αυτούσιος στο ενοποιημένο JSON.

| Αρχείο | Περιεχόμενο |
|---|---|
| Seismic-Cartomancy-Research-Phase-2.pdf / Study.md | Επικαιροποιημένη μελέτη και επεξεργάσιμη μορφή. |
| knowledge.json / knowledge.csv | Πλήρης δίγλωσση βάση. Το JSON περιέχει κύριες εγγραφές, παράρτημα, βιβλιογραφία, ευρετήριο και πρόσθετες μαρτυρίες. Το CSV έχει 1.326 γραμμές δεδομένων. |
| comparison.tsv / statistics.json | Σύγκριση πριν και μετά και αναλυτικά στατιστικά. |
| coverage-by-card.tsv | Έκταση εμπλουτισμού και αναγνωριστικά ανά φύλλο. |
| sources.tsv / prior-works-review.tsv | Βιβλιογραφία, σύνδεσμοι, κατάσταση πρόσβασης και δελτίο των 33 αρχικών έργων. |
| methods-phase-2.tsv | Διαδικαστική σύγκριση EL/EN όσων προστέθηκαν ή επανελέγχθηκαν. |
| conflicts.json / non-transcribed-conditions.json | Διαφωνίες, αμφισημίες και έντυπα κενά. |
| editorial-examples.json | Οκτώ σύγχρονες αποδόσεις EL/EN με αναγνωριστικά τεκμηρίων. |
| audit.json | Αποτελέσματα ελέγχου ακεραιότητας. |
| baseline-* | Οι προηγούμενες μεθοδολογικές συγκρίσεις, παραδείγματα, εκδοτικοί κανόνες και γλωσσάρι. |

Τα CSV είναι UTF-8 με BOM, τα JSON και TSV UTF-8. Στο JSON `entries` είναι ο κυρίως κατάλογος, `archival_positions` το παράρτημα, `supporting_witnesses` οι πρόσθετες βιβλιογραφικές συνδέσεις. Η απαρίθμηση του `by_card` αφορά ρητά φύλλα του κυρίως καταλόγου. Οι θέσεις που εφαρμόζονται σε οποιοδήποτε φύλλο ενός συμβόλου παραμένουν συμβολικές. Το `D*` δηλώνει οποιοδήποτε καρό, το `Q*` οποιαδήποτε ντάμα, το `F*` οποιαδήποτε φιγούρα, το `FD*` φιγούρα καρό και το `ANY*` γενικό στοιχείο ή θέση. Επαναλαμβανόμενα μοτίβα παραπέμπουν σε διαφορετικά φύλλα όπου το απαιτεί η πηγή. Το πεδίο `cards` είναι ερευνητικός δείκτης. Οι ρητές προϋποθέσεις τεκμηριώνονται στα `conditions`, στην πρωτότυπη περιγραφή και στην πηγή. Όλες οι εγγραφές της δεύτερης φάσης έχουν `runtime_eligible: false`.

Οι ενδείξεις είναι ιστορικό και ψυχαγωγικό υλικό. Το πακέτο παρέχει πρωτότυπες αποδόσεις και συνδέσμους προς τις πηγές. Για το πλαίσιο απόδοσης του έργου, βλ. [Σεισμική Χαρτομαντεία](https://github.com/dosgr/Seismic-Cartomancy).
